# 🔍 AI Image Metadata Remover

A lightweight Python desktop application designed to remove hidden metadata and EXIF information from images through a simple and user-friendly graphical interface.

Protect your privacy by cleaning image metadata in just a few clicks!

## ✨ Features

- 🧹 **Metadata Removal:** Remove hidden metadata and EXIF information from images.
- 🖼️ **Image Information:** Display file name, file size, image format, and dimensions.
- ⚡ **Simple Interface:** Clean and easy-to-use graphical user interface.
- 📂 **Image Selection:** Select images using the Browse button.
- 📊 **Progress Indicator:** Monitor the metadata removal process.
- 📝 **Operation Log:** View processing status and messages.
- 🔄 **Clear Function:** Reset the interface and select another image.

## 🚀 How to Use

Using the application is simple. Follow these steps:

### 1. Launch the Application

Run the application to open the main graphical interface.

### 2. Select an Image

Click the **Browse** button in the Select Image section.

Choose the image you want to process from your computer.

### 3. Review File Information

After selecting an image, the application displays:

- File Name
- File Size
- Image Format
- Image Dimensions

### 4. Remove Metadata

Click the **Remove Metadata** button to start the cleaning process.

The application will process the selected image and update the progress bar.

### 5. Check the Result

Once processing is complete, a success message will appear:

`Complete! Metadata removed.`

### 6. Clear and Process Another Image

Click the **Clear** button to reset the interface and select another image.
